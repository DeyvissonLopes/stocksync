## Part B — External-service mock and asynchronous sync

| Assessment requirement | Exact test evidence |
| --- | --- |
| The mock accepts batches of SKU, stock, and price updates. | [`applies a batch atomically and ACKs exactly its event IDs`](apps/api/test/mock-sync.integration.spec.ts#L70); [`accepts exactly 50 updates in one batch`](apps/api/test/mock-sync.integration.spec.ts#L140) |
| The mock allows at most five requests per second. | [`rejects the sixth request in a moving second and provides Retry-After`](apps/api/test/mock-sync.integration.spec.ts#L151) |
| The mock fails randomly about 20% of the time, including errors and timeouts. | [`produces 10% errors and 10% timeouts in demo mode across controlled draws`](apps/api/test/mock-sync.integration.spec.ts#L220); [`uses deterministic demo draws for error and timeout before or after apply`](apps/api/test/mock-sync.integration.spec.ts#L197) |
| The mock can receive the same update twice. | [`ACKs repeated and stale updates without overwriting the newest version`](apps/api/test/mock-sync.integration.spec.ts#L83); [`can fail before applying or timeout after applying, then safely ACK a retry`](apps/api/test/mock-sync.integration.spec.ts#L166) |
| Detect stock and price changes and publish them asynchronously. | [`records stock adjustments with the supplied reason and snapshots each changed version`](apps/api/test/product-update.integration.spec.ts#L108); [`creates an outbox snapshot for a price-only change without a stock movement`](apps/api/test/product-update.integration.spec.ts#L148); [`moves committed snapshots from API through PostgreSQL queue to mock and status`](apps/api/test/sync-flow.integration.spec.ts#L109) |
| A sale request must not wait for the external service. | [`commits a sale while an external batch request is still waiting for a response`](apps/api/test/sync-flow.integration.spec.ts#L154) |
| Send updates in batches while respecting the external rate limit. | [`claims at most 50 ordered pending events from one tenant, then leaves no empty batch`](apps/api/test/sync-batcher.integration.spec.ts#L125); [`paces HTTP starts globally across tenants within a rolling second`](apps/api/test/sync-batch-processor.integration.spec.ts#L179); [`waits for Retry-After before retrying HTTP 429`](apps/api/test/sync-batch-processor.integration.spec.ts#L208) |
| Retry transient failures with backoff. | [`retries a transient HTTP failure and confirms the next successful attempt`](apps/api/test/sync-batch-processor.integration.spec.ts#L149); [`doubles the retry delay after each transient failure with a controlled jitter draw`](apps/api/test/sync-retry.spec.ts#L5); [`persists one job for a tenant batch across queue connections`](apps/api/test/sync-job-publisher.integration.spec.ts#L27) |
| Stop after a maximum number of attempts and mark updates failed or send them to a dead-letter queue. | [`fails the batch and events after five invalid ACKs without a sixth call`](apps/api/test/sync-batch-processor.integration.spec.ts#L351); [`closes an exhausted reservation after restart without a sixth HTTP call`](apps/api/test/sync-batch-processor.integration.spec.ts#L335); [`mirrors a retained failed job to the batch and its pending events`](apps/api/test/sync-batch-reconciler.integration.spec.ts#L26) |
| Duplicate or out-of-order delivery must not overwrite newer values. | [`ACKs repeated and stale updates without overwriting the newest version`](apps/api/test/mock-sync.integration.spec.ts#L83); [`rejects a different payload at the same version and rolls back the whole batch`](apps/api/test/mock-sync.integration.spec.ts#L97) |
| Expose pending, sent, failed, and last-successful-sync status per tenant. | [`counts events and the latest confirmed batch only for the admin tenant`](apps/api/test/sync-status.integration.spec.ts#L112); [`shows only the operator tenant and null when no batch was confirmed`](apps/api/test/sync-status.integration.spec.ts#L122) |
| Preserve tenant isolation in background jobs. | [`refuses a tenant mismatched with the batch before any HTTP call`](apps/api/test/sync-batch-processor.integration.spec.ts#L137); [`links an outbox event only to a batch from its own tenant`](apps/api/test/sync-batches-schema.integration.spec.ts#L89) |
| Push changed values so ads do not promote out-of-stock items. | [`moves committed snapshots from API through PostgreSQL queue to mock and status`](apps/api/test/sync-flow.integration.spec.ts#L109) proves eventual delivery; an immediate guarantee is outside the asynchronous design. |
